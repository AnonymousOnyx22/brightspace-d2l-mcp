Set up in about a minute

  1. Run one command in a terminal: npx brightspace-d2l-mcp setup
  2. Enter your school. Paste any Brightspace link from your browser.
  3. Sign in like you always do. A normal browser window opens, so Microsoft, Duo, Okta, Shibboleth and text codes all work.
  4. Done. Setup connects every AI app it finds. Ask "What should I work on right now?"

FAQ

Does it work at my school?

If your school uses D2L Brightspace, yes. Setup opens a normal browser window so any sign-in works, including Microsoft, Duo, Okta and Shibboleth. It's been tested at one college.

Is my password saved?

No. You type your password into your school's own sign-in page in a real browser. The tool only keeps the session, on your own computer.

Can it submit work or change anything?

No. Every tool is read-only and only ever reads from Brightspace. A test in the code fails if that ever changes.

Where does my data go?

Nowhere except your own AI app. It runs on your computer and talks only to your school's Brightspace, with no server in between and no analytics.

Does it cost anything?

No. It's free and open source under the MIT license.

Something isn't working

Run npx brightspace-d2l-mcp doctor. It checks everything and tells you how to fix it. Or open an issue.
